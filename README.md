# DayZ Zoom & Reticle Tool

Профессиональная утилита для увеличения области экрана (лупа) и наложения кастомного прицела (сетки), специально разработанная для DayZ, но подходящая и для других игр.

## Основные возможности

- **Умный Зум:** Увеличение центральной части экрана с настраиваемым коэффициентом (2x - 10x).
- **Кастомные прицелы:** Выбор из нескольких типов сеток (точка, перекрестие, круг, Т-образный).
- **Привязка к окну:** Автоматическое обнаружение окна игры — зум работает только когда вы в игре.
- **Поддержка комбинаций клавиш:** Настройка сложных горячих клавиш (например, `Ctrl+F2` или `Alt+Shift+X`).
- **Режим заморозки (Freeze):** Возможность "заморозить" текущее увеличенное изображение для детального изучения.
- **Звуковая индикация:** Приятные бипы при переключении режимов.
- **Удобные настройки:** Полностью настраиваемый интерфейс с выбором цвета, размера окна и прозрачности.
- **Работа в фоне:** Сворачивается в системный трей.

## Установка

1. Убедитесь, что у вас установлен **Python 3.8+**.
2. Установите необходимые библиотеки:

```bash
pip install pynput Pillow pystray
```

*Примечание: Библиотеки `tkinter`, `ctypes` и `winsound` обычно входят в стандартную поставку Python для Windows.*

## Запуск

Запустите скрипт командой:

```bash
python dayz_zoom.py
```

После запуска в системном трее (возле часов) появится иконка программы.

## Инструкция по использованию

### Горячие клавиши по умолчанию:
- **F2:** Переключение постоянного зума (Вкл/Выкл).
- **Ctrl (зажать):** Временный зум (работает, пока удерживаете клавишу).
- **Колесо мыши (во время зума):** Плавное изменение кратности увеличения.
- **Средняя кнопка мыши (клик):** Сброс зума до стандартного значения (3.0x).
- **F3:** Заморозка изображения (работает только при активном зуме).

### Как настроить:
1. Кликните правой кнопкой мыши по иконке в трее и выберите **Settings**.
2. **Изменение клавиш:** Нажмите на кнопку с названием клавиши и нажмите новую клавишу (или комбинацию клавиш) на клавиатуре.
3. **Настройка прицела:** Выберите тип сетки в выпадающем списке, настройте её прозрачность ползунком или выберите любой цвет через кнопку "Choose Color".
4. **Привязка к игре:** В поле "Target Window Title" введите часть заголовка окна вашей игры (по умолчанию "DayZ"). Если оставить поле пустым, зум будет работать везде.
5. **Размер окна:** Ползунок "Window Size" меняет размер области увеличения.

## Требования
- Операционная система: **Windows 10/11** (использует Windows Magnification API).
- Python 3.8 или выше.
